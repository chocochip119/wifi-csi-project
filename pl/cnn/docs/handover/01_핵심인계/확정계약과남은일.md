# 확정 계약과 남은 일

## 인계 시 유지할 계약

- reset: 동기식 active-low. 최소 한 상승 에지를 포함해야 한다. BD에서 실제 reset 생성·범위·AXI 복구 절차 검증은 별도다.
- D01~D05: CSR 원자적 쓰기/상태 clear 우선순위/START snapshot/정렬 규칙은 PROJECT_CONTEXT 5.1절을 참조한다.
- D06: FC1 read base는 현재 WEIGHT_ADDR가 아니라 LOAD 당시 보관값이다.
- D08: 오류 발견 cycle부터 소비 쓰기 차단. read 오류는 ERR_DRAIN에서 남은 응답 처리.
  BAD_CMD(1)/NO_CFG(2)는 재요청, 실행 오류(3/4/5)는 reset→재LOAD→재INFER.
  RD_FAULT에서는 busy가 유지되고 FINISH에 도달하지 않아 STATUS.error=0일 수 있다. PS timeout 뒤 검증된 reset 절차가 필요하다.
- D09: Top의 param_sel_fc/lut_sel_fc가 FC1~FC3에서 1. Loader가 Param/LUT 읽기 주소를 선택한다.
- RAM 읽기 1 cycle. Param 96-bit는 {shift,mult,bias}; FC base는 48/176/304, Conv base는 0/16.
- FIFO push는 full일 때 금지. 정상 FC1은 fifo_we=mem_rd_valid&&!fifo_full, mem_rd_ready=!fifo_full.
- LOAD는 offset 0에서 5,936 B + offset 399,152에서 23,840 B. 입력 11,520 B, FC1 393,216 B, pose 24 B.
- INPUT/WEIGHT 주소는 8 B 정렬, OUTPUT 주소는 32 B 정렬. 데이터 byte 순서는 낮은 주소가 word 하위 byte다.

## 남은 일 / 결정 주체

| 항목 | 현재 상태 | 결정/후속 주체 |
|---|---|---|
| 실물 FC 완성/연결 | 저장소·MAC·requant 검증까지. 후처리·제어 결합 미완료 | FC 담당자·팀 |
| Encoder 수정 채택 | Buffer 등가성/golden 결과 있음. 원본과 패치 제공 | Encoder 담당자 |
| 100 MHz 타이밍 | E-02a 기본/성능 P&R 모두 미달; requant 외 Conv MAC/Pool 경로도 있음 | 관련 모듈 담당자·팀 |
| D10 | 최종 클록 미확정. 71.429 MHz는 Encoder OOC 통과점 | 사용자·팀 |
| BD/PS/reset | 실제 reset 범위, clock, 주소 매핑, DDR 연결 및 보드 검증 남음 | 통합/PS 담당자 |
| 최종 end-to-end | 실물 FC 포함 전체 pose/보드 대조 남음 | 통합 담당자 |

파이프라인 분할이나 Pool multicycle 예외는 아직 인계 확정 구현이 아니다.
LOAD 후 설정값 유지라는 사실만으로 타이밍 예외를 바로 넣지 말고 capture 시점·setup/hold·reset/갱신 관계를 통합에서 입증해야 한다.
현재 구간 분해 수치만으로 “레지스터 한 단이면 충분/불충분”을 확정하지 않는다.

## 기존 문서 주의사항

- PROJECT_CONTEXT.md 앞부분의 T-05 미완료와 뒤쪽 최신 완료 기록이 혼재한다. 인계 요약/최신 단계 근거와 함께 읽는다.
- rtl/CNN_Encoder/README.md는 E-01 당시 계획이며, 이후 F-03a에서 requant_stage가 파라미터화됐다.
- S00_AXI_민영_인계.md의 오래된 SHA/reset/검증 범위는 작성 당시 값이다. 현재 파일 해시는 이번 manifest를 사용한다.
- draw.io는 목표 설계 도면이다. D06 확정, done 보관, 등록된 주소, 오류 cycle 쓰기 차단, D09 추가 포트 등은 현재 RTL·단계 기록을 같이 본다.
- doc/preview/STALE.txt가 있는 미리보기는 최신 도면으로 간주하지 않는다. draw.io 원문을 연다.
- 과거 보고서의 절대 파일 링크/실행 스크립트는 당시 PC 경로다. project 아래 같은 상대 경로 자료를 찾는다.

최신 타이밍 근거: [E-02a 측정 기록](../../E-02a_측정기록.md).
